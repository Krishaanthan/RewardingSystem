
# 🎖 Tier Upgrading Badge System

Each badge has **4 levels**:

🥉 Bronze → 🥈 Silver → 🥇 Gold → 💎 Diamond

When a student completes more activities, the **same badge upgrades**.

---

# 1️⃣ Knowledge Seeker Badge (Learning & Certifications)

Activities Included

- Swayam NPTEL course
    
- Coursera Course
    
- NPTEL 12 week course
    
- External Certification
    
- Global Certification
    

Badge Name: **Knowledge Seeker**

|Tier|Requirement|
|---|---|
|🥉 Bronze|Complete 1 course|
|🥈 Silver|Complete 3 courses|
|🥇 Gold|Complete 5 courses|
|💎 Diamond|Complete 8+ courses|

Badge progression  
Knowledge Seeker → **Knowledge Explorer → Knowledge Master → Global Scholar**
