# Image assets

Place the **faculty login background** (campus/building image) here as:

- **Filename:** `faculty-login-bg.png`
- **Format:** PNG (or use the same filename with .jpg if you prefer; update the path in `FacultyAuthLayout.tsx` to match)

The image will be used as the full-width background on the faculty login page. Use an HD, clear image for best results.
